# DobbyVPN F-Droid repository

This repository distributes official DobbyVPN Android releases signed by the
DobbyVPN project. Add `https://f-repo.dobbyvpn.com/fdroid/repo` in the F-Droid
app, or scan the QR code on the repository website:

[https://f-repo.dobbyvpn.com](https://f-repo.dobbyvpn.com)

The repository fingerprint is published in [repository.json](repository.json)
and on the website. Check it when adding the repository manually. These APKs
are signed with DobbyVPN's Android release certificate and distributed under
the Business Source License 1.1.
